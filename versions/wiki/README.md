# Wiki source provenance

This directory holds collection-wide records for update notes stored in the
individual version directories. `manifest.json` records each page's source and
revision URLs, contributor-history link, timestamps, hash, and version links.
`categories.json` records traversed update categories; `support/` preserves the
category, navigation, history, and infobox source used to establish coverage.

The source API reports CC BY-NC-SA terms. Wikitext retains those source terms and
is not relicensed as project code. Each captured release page links to its source
and fixed revision from its README.
